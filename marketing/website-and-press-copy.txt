Introduction
MediaMuster is a media manager for Avid editors and assistants on macOS and Windows. Scan your media drives to see which files belong to each project. When another room needs a bin, open its .avb in Filter by Bin and copy the matching media to a shuttle drive.

Scan the drive
Read the clip name, project and file path on the same row. Select a project to see its files and how much space they take up.

Load the bin
A bin can reference media from several folders or drives. Load the bin to pull those files into one list. If you need the list for a handover, export it as a CSV.

Check the copy
Choose a destination and tick Preserve Avid folder structure. The preview shows the path every selected file will take, down to the numbered MXF folder on the receiving drive.

One sentence
MediaMuster shows Avid editors where a bin’s media lives and lets them copy it to another drive.

Short description
MediaMuster is a desktop media manager by Marty McLean for editors and assistants working in Avid Media Composer. It scans Avid-managed MXF OP-Atom folders and lists each file alongside its clip, bin and project metadata. Editors can filter that inventory with an Avid bin, copy or move the media they select, and export a file list as a CSV. MediaMuster runs on macOS and Windows.
