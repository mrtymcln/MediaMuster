# AVB review evidence

See [the review](../../avb-review-2026-09-05.md) for findings and their limits. `manifest.json` pins the reviewed product source and captured evidence. The inputs were read only; this directory contains analyst notes, probe sources, results and tiny independently generated fixtures.

- [Corpus summary](corpus/summary.json): 42 real file paths, 40 distinct file contents, plus four minimal constructed cases. Counts distinguish IDs from matched media rows. Five pyavb descriptor failures are explicitly recorded.
- [Corpus replay](corpus/README.md): rebuild the actual C++ parser probe and run the attached pyavb comparison. Scripts use the original review machine's absolute paths. Restore this `corpus/` directory to `/tmp/mediamuster-avb-review/corpus/` to replay unchanged; the original attached sources and Avid Projects directory are also required. `join_media.py` additionally requires the prior media audit export identified in the summary.
- [Consumer findings](consumer-probe/review.md) and [results](consumer-probe/results.json): real dialog/proxy Intersect, Subtract, empty-bin and chain-edit behavior. Restore to `/tmp/mediamuster-avb-review/consumer-probe/`, configure its CMake project with the local Qt 6.5.3 prefix, build, then run `avb-consumer-probe` with `QT_QPA_PLATFORM=offscreen`. The fixture `empty-real.avb` is a genuine pyavb-created empty object document; the other consumer buffers intentionally isolate ID-set behavior.
- [Metadata ownership](metadata/original-bin-owners.json): 80 `CMPO` owners and their `_ORG_BIN` → `MCBR` references across the 16 attached/repository bins. [Replay script](metadata/inspect_metadata.py) reads the supplied pyavb and AVBs and writes results beside itself.
- [Binary analysis](binary/evidence.md): inspected symbols, addresses, normalized interpretation and limitations. [Provenance](binary/provenance.json) pins the two universal binaries and arm64 slices. [Hopper targets](binary/decompile-ame.py) and [core targets](binary/decompile-core.py) record precisely which procedures were requested. The full assembly and raw pseudocode remain under `/tmp/mediamuster-avb-review/binary/`; 20 of 21 selected procedures yielded pseudocode, and all selected functions have assembly evidence.

No Avid binaries or raw decompiled source are distributed here. The analyst's binary note contains short normalized explanations and selected assembly instructions. This package does not claim full AVB support, successful loading of the generated bins in Media Composer, or a fresh live media scan.
